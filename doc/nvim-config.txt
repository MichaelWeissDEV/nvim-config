1. OVERVIEW                                                        *nvim-config-overview*

A from-scratch, fully documented Neovim configuration. No plugin manager
downloads anything at startup; all plugins are vendored in pack/vendor/ via
git subtree. See |nvim-config-offline| in the Sphinx docs (./scripts/docs-build.sh)
for the full offline-usage explanation, and :NvimConfigHealth for a live report
of what's installed on this machine.

2. COMMANDS                                                        *nvim-config-commands*

:DebuggerStatus                                              *nvim-config-cmd-debuggerstatus*
    Show which languages have a debugger configured and whether its adapter binary is installed

:LinterStatus                                                *nvim-config-cmd-linterstatus*
    Show which linter(s) are configured/available for the current buffer, and all linters by filetype

:NvimConfigHealth                                            *nvim-config-cmd-nvimconfighealth*
    Run the structured health report for this config (alias for :checkhealth nvim-config)

:NvimCommands                                                *nvim-config-cmd-nvimcommands*
    List every command this config defines, grouped by category

:NvimDocs                                                    *nvim-config-cmd-nvimdocs*
    Open local documentation: built Sphinx HTML if available, else :help nvim-config

:NvimKeymaps                                                 *nvim-config-cmd-nvimkeymaps*
    List every keymap this config defines, grouped by group

:Format                                                      *nvim-config-cmd-format*
    Format the current buffer

:FormatDisable                                               *nvim-config-cmd-formatdisable*
    Disable format-on-save globally

:FormatEnable                                                *nvim-config-cmd-formatenable*
    Enable format-on-save globally

:FormatStatus                                                *nvim-config-cmd-formatstatus*
    Show whether format-on-save is currently active for this buffer, and why

:FormatToggle                                                *nvim-config-cmd-formattoggle*
    Toggle format-on-save (buffer-local; add ! for global)

:FormatterStatus                                             *nvim-config-cmd-formatterstatus*
    Show which formatter(s) are configured/available for the current buffer, and all formatters by filetype

:Git [git-subcommand]                                                         *nvim-config-cmd-git*
    Run any git command through vim-fugitive; bare :Git opens the interactive status buffer

:Gitsigns                                                    *nvim-config-cmd-gitsigns*
    Gitsigns subcommands (staging, blame, hunks)

:Gvdiffsplit                                                 *nvim-config-cmd-gvdiffsplit*
    Open a vertical three-way diff of the current file against the index (fugitive)

:LspStatus                                                   *nvim-config-cmd-lspstatus*
    Show configured LSP servers (installed) and clients attached to the current buffer

:NvimTreeFindFile                                            *nvim-config-cmd-nvimtreefindfile*
    Open nvim-tree and reveal the current buffer's file

:NvimTreeToggle                                              *nvim-config-cmd-nvimtreetoggle*
    Toggle the nvim-tree sidebar

:Oil                                                         *nvim-config-cmd-oil*
    Open Oil file explorer

:TSInstall <language>                                                   *nvim-config-cmd-tsinstall*
    Install a Tree-sitter parser (network; explicit action only)

:TSUpdate                                                    *nvim-config-cmd-tsupdate*
    Update installed Tree-sitter parsers (network; explicit action only)

:Telescope <picker>                                                   *nvim-config-cmd-telescope*
    Open a Telescope picker by name

:Trouble                                                     *nvim-config-cmd-trouble*
    Open Trouble (diagnostics/quickfix/loclist list)

:Mason                                                       *nvim-config-cmd-mason*
    Open the Mason installer UI

:MasonInstall <package>...                                                *nvim-config-cmd-masoninstall*
    Install a specific Mason package (network; explicit action only)

:MasonUpdate                                                 *nvim-config-cmd-masonupdate*
    Refresh the Mason registry (network; explicit action only)

:ToolsInstall <profile>                                                *nvim-config-cmd-toolsinstall*
    Install every Mason-installable tool for a profile (core, systems, python, web, jvm, dotnet, functional, devops, docs, scripting, all)

:ToolsStatus                                                 *nvim-config-cmd-toolsstatus*
    Show installed/missing status for every LSP/formatter/linter/debugger this config knows about

:ToolsUpdate <profile>                                                 *nvim-config-cmd-toolsupdate*
    Update every Mason-installed tool for a profile (or 'all')

:RelativeNumbersToggle                                       *nvim-config-cmd-relativenumberstoggle*
    Toggle relative/absolute line numbers in the current window

3. KEYMAPS                                                         *nvim-config-keymaps*

Buffer ~

    n      <S-h>              Previous buffer
    n      <S-l>              Next buffer
    n      <leader>bd         Delete buffer
    n      <leader>bo         Close other buffers
Debug ~

    n      <leader>dB         Conditional breakpoint
    n      <leader>dO         Step out
    n      <leader>db         Toggle breakpoint
    n      <leader>dc         Start / Continue
    n      <leader>di         Step into
    n      <leader>dl         Run last configuration
    n      <leader>do         Step over
    n      <leader>dr         Toggle REPL
    n      <leader>dt         Terminate session
    n      <leader>du         Toggle debug UI
Diagnostics ~

    n      <leader>xl         Line diagnostics (float)
    n      <leader>xq         Diagnostics to quickfix
    n      <leader>xt         Toggle diagnostics in this buffer
    n      <leader>xv         Toggle inline diagnostic details (virtual_lines)
    n      <leader>xx         Toggle diagnostics list (Trouble)
    n      [d                 Previous diagnostic
    n      ]d                 Next diagnostic
Find ~

    n      -                  Open parent directory (Oil)
    n      <leader>e          Toggle file explorer (nvim-tree)
    n      <leader>fG         Git files
    n      <leader>fb         Find buffers
    n      <leader>fc         Commands (all of Neovim's)
    n      <leader>fd         Diagnostics
    n      <leader>ff         Find files
    n      <leader>fg         Live grep
    n      <leader>fh         Help tags
    n      <leader>fk         Keymaps (all of Neovim's)
    n      <leader>fr         Recent files
    n      <leader>fs         Document symbols
    n      <leader>o          Open file explorer (Oil)
Format ~

    n,v    <leader>lf         Format buffer
General ~

    v      <                  Indent left, keep selection
    n      <C-d>              Half-page down, centered
    n      <C-u>              Half-page up, centered
    n      <Esc>              Clear search highlight
    n      <leader>Y          Yank line to system clipboard
    n,v    <leader>y          Yank to system clipboard
    v      >                  Indent right, keep selection
Git ~

    n      <leader>gP         Git pull
    n      <leader>gc         Git commit
    n      <leader>gd         Git diff against index (split)
    n      <leader>gg         Git status (fugitive)
    n      <leader>gl         Git log (graph)
    n      <leader>gp         Git push
Help ~

    n      <leader>hc         List commands
    n      <leader>hd         Open documentation
    n      <leader>hh         Run health check
    n      <leader>hk         List keymaps
UI ~

    n      <leader>uF         Toggle format on save (global)
    n      <leader>uN         Toggle line numbers on/off
    n      <leader>uf         Toggle format on save (buffer)
    n      <leader>ul         Toggle whitespace display
    n      <leader>un         Toggle relative/absolute line numbers
    n      <leader>uw         Toggle line wrap
Window ~

    n      <C-h>              Go to left window
    n      <C-j>              Go to lower window
    n      <C-k>              Go to upper window
    n      <C-l>              Go to right window
    n      <leader>wc         Close window
    n      <leader>we         Equalize window sizes
    n      <leader>ws         Split window horizontally
    n      <leader>wv         Split window vertically
